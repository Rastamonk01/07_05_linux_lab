# 07_05 Linux Lab

A simple Linux bash scripting exercise demonstrating user input handling.

## Description

This lab project contains a basic bash script that demonstrates how to interact with users by prompting for input and displaying personalized output.

## Files

- `user_input.sh` - Main bash script that prompts for and displays user name
- `README.md` - This documentation file

## Usage

Run the script with:

```bash
./user_input.sh
```

The script will:
1. Prompt you to enter your name
2. Read your input
3. Display a personalized greeting

## Requirements

- Bash shell
- Execute permissions on the script
